# Notagram

Notagram is a journaling app focused on photos and videos.

Users can create journal entries by uploading photos and videos, adding a song to set the mood, and writing a caption. The caption serves as the journal entry, while the media provides the visual context.

## Features

- Upload photos and videos to journal entries
- Add a song to an entry
- Write captions as journal entries
- End-to-end encryption
- No personal information stored by the service

## Privacy

Notagram is designed around keeping journal data private. Journal entries and their associated media are end-to-end encrypted, so the service cannot read the contents of your entries.

Notagram also does not store personal information.
